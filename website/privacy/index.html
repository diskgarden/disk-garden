Privacy

DiskGarden is built to look at your disk without looking at you. Here is exactly what goes online.

Your files stay on your Mac

Scanning happens entirely on your Mac. The map, the names and sizes of your files and folders, and your saved scan results are stored locally (in ~/Library/Application Support/DiskGarden) and are never uploaded. DiskGarden has no account, no ads and no analytics.

What does go online

Update checks

A few times a day DiskGarden downloads a small list of available versions from diskgarden.app (using the open-source Sparkle framework), and downloads an update when there is one. Like any web request, this reveals your IP address and the app's version to the server.

Crash reports

If DiskGarden crashes or hits a serious error, it sends a report using Firebase Crashlytics (Google): the app and macOS versions, the Mac model, what the app was doing in code at the time, and the error message. An error message can occasionally include the path of the file or folder involved. Reports are tied to a random installation ID, not to you, and are used only to fix bugs.

Remote settings

DiskGarden fetches a few settings from Firebase Remote Config (Google), so features can be tuned or switched off without a new release. This request also uses the random installation ID.

Google's handling of this data is described in the Firebase privacy and security documentation.

This website

diskgarden.app uses no cookies, no analytics and no trackers. It is hosted on GitHub Pages, which may log visitors' IP addresses for security; see GitHub's privacy statement.
