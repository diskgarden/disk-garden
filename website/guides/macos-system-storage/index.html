Why does macOS take up so much space on my Mac?

In Storage settings, the "macOS" bar alone can be tens of gigabytes — before you've installed anything. Here's what's in it, what's fixed, and what you can actually reclaim.

What counts as "macOS"

Open System Settings → General → Storage and hover the bar. The macOS category is the operating system itself plus the files it needs to run, update and recover:

  • The system volume. Since macOS Big Sur, the system lives on a separate, read-only, cryptographically sealed volume. Nothing on it can be removed — and you wouldn't want to: the seal is what lets your Mac check the system hasn't been tampered with.
  • Recovery and Preboot. Small hidden volumes that let your Mac start up and reinstall macOS when something goes wrong.
  • Swap and sleep files in /System/Volumes/VM. When apps need more memory than you have, macOS writes some of it to swap files; the sleep image holds memory while the Mac sleeps. Both shrink on their own.
  • Downloaded system assets — fonts, dictionaries, voices, language and machine-learning models (including Apple Intelligence) — kept in /System/Library/AssetsV2.
  • Software updates that have been downloaded but not installed yet.

Some of what people think of as "macOS" is actually counted as System Data instead: caches, logs and Time Machine snapshots.

What you can reclaim

Install (or clear) a pending update

A downloaded macOS update can take several gigabytes until it's installed. Install it from System Settings → General → Software Update; afterwards the download is removed.

Restart to shrink swap

If you've had heavy apps open for days, swap files may have grown to many gigabytes. Quitting memory-hungry apps or restarting your Mac lets macOS remove them.

Remove downloaded voices and features you don't use

  • Extra Siri and spoken-content voices: System Settings → Accessibility → Spoken Content → System voice → Manage Voices…
  • Apple Intelligence's on-device models, if you don't use it: see How much storage Apple Intelligence uses.

Leave the rest alone

The sealed system volume, Recovery and Preboot can't (and shouldn't) be trimmed by hand. "Cleaner" apps that promise to shrink macOS itself mostly delete caches that come straight back.
